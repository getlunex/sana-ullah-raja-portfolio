# Sana Ullah Raja — Public Portfolio

A responsive single-page portfolio website presenting Sana Ullah Raja's experience across IT infrastructure, cybersecurity practice, sales and digital marketing, and education.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. GitHub Pages will show the public website URL on that settings page after deployment completes.

This repository is public because the portfolio site is intended to be public. It does **not** contain a CV or cover letter. Do not add private documents, identity documents, passwords, or verification codes here.
